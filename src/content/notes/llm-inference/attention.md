注意力机制可以先理解成一句话：**根据当前问题，从已有信息中找到最相关的部分，再按相关程度汇总。**

## 三个角色

设想你带着一个问题去查资料：

1. Query（查询）描述“我现在想找什么”；
2. Key（键）描述“每条资料可以被怎样检索”；
3. Value（值）是资料真正携带的内容。

Query 与每个 Key 计算相似度，得到权重；权重归一化后，再对对应的 Value 做加权求和。

## 为什么要除以根号维度

向量维度变大时，点积的数值范围也会变大。过大的输入会让 softmax 很快进入饱和区，梯度变得很小。除以 `sqrt(d_k)` 的作用，是让不同维度下的数值尺度保持相对稳定。

## 多头并不只是“算很多次”

每个注意力头拥有不同的投影矩阵，因此可以在不同表示子空间中建立关联。有的头可能更关注局部语法，有的头可能更关注跨句指代。

这不意味着每个头都会形成清晰、固定的人类概念，但它给模型提供了同时表达多种关系的容量。
